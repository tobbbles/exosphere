# Lexicon sources

Vendored lexicon JSON files are snapshots of upstream sources, pinned by hand
when refreshed. Regenerate modules with `mix exosphere.gen.bsky` after changes.

| Path | Source |
|------|--------|
| `app/bsky/**` | https://github.com/bluesky-social/atproto/tree/main/lexicons |
| `community/**` | https://tangled.org/lexicon.community/lexicons/tree/main/community (canonical; github.com/lexicon-community/lexicon is a mirror) |
